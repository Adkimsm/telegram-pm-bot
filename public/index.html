如何准备中转群
  1. 新建一个群组（Telegram 无法让 bot 代建）。
  2. 群组设置里开启「话题」（Topics）。开启后群会升级为超级群。
  3. 把本 bot 加入该群，并设为管理员。
  4. 管理员权限中勾选「管理话题」（Manage topics）。缺此权限无法建话题。
  5. 回到这里，在下面的候选群里点「绑定」。

候选群

在群里发 /id 可查看当前群组 ID。

陌生人首次交互

陌生人发送 /start 时的回复，此消息不会转发给你。

转发行为

你回复时始终使用复制，与此项无关——转发会让对方看到「转发自 <中转群名>」，泄露架构。
一次发送的多张图保持为一组。关闭后会拆成多条独立消息。
任一方编辑消息时同步到另一侧。删除无法同步：Telegram 不向 bot 推送删除事件，需在话题内回复该消息并发送 /del（限 48 小时内）。

限流

超限的消息直接丢弃，并在对应话题内提示你一次。

用户

拉黑用户

被拉黑者的消息会被静默丢弃，不会收到任何提示——告知只会促使其换号绕过。

黑名单

Webhook

Webhook 地址与密钥均由 BOT_TOKEN 派生，无需手动配置。更换 token 后需重设。

数据清理

每日自动执行。清理过期的去重记录、会话、登录令牌，以及 60 天前的消息映射。

会话

失效所有网页会话，包括当前这个。也可以在 Telegram 里发送 /revoke。

恢复与备份

  • D1 Time Travel 始终开启，免费版可回溯 7 天：wrangler d1 time-travel restore pmbot-db --timestamp=…
  • 实时日志：wrangler tail
  • 数据库迁移：npm run db:migrate
  • 丢失控制台访问：给 bot 发 /claim <认领码>，认领码由 npm run claim-code 生成。
